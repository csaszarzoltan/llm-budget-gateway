# Control Center

Run `uvicorn llm_budget_gateway.control_api:create_control_app --factory --port 8001`. The `/control` interface supports desktop, tablet and mobile layouts, semantic navigation, skip link, visible focus, live status, non-color-only state, and keyboard-operable actions. Its API is under `/v1/admin`; every request requires `X-Tenant-Id` and `X-Role`. Roles are viewer, auditor, operator, security and admin. Key secrets are returned once and stored as SHA-256 digests. Budget reservations are transactional and reconciled exactly once. Policy evaluation denies when no active policy exists and records only decision metadata, never prompt content. Route circuits open after three failures for 60 seconds; cache entries have route-defined TTLs. Recovery uses the same idempotency key after a timeout. Community mode uses one SQLite process; use a transactional distributed adapter before multi-instance production.
