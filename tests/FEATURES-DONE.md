## Features Done (this pass)
- Route Inventory: Searchable and filterable table with status, strategy, version, health and contextual actions.
- Visual Fallback Designer: Start, ordered model, fallback edge and terminal response visualization.
- Route Target Inspector: Model, retry, timeout, schedule, capability, status-code, condition, weight and cost controls.
- Accessible Reordering: Keyboard-operable Move up and Move down controls without requiring drag gestures.
- Draft and Publish Workflow: Isolated immutable draft versions, validation, simulation, publication and history.
- Route Simulation: Explains the selected target and decision path without making a provider call.
- Dependency-Aware Archive: Blocks archival while applications reference the route and preserves recoverable history.
- Restore and Permanent Delete: Restores archived routes or deletes them only after exact-name confirmation.
- Route Duplication: Creates an independent draft from an existing route configuration.
- Responsive Route Studio: Desktop three-panel workspace with tablet and mobile adaptations.
