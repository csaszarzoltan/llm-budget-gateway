## Features Done (this pass)
- Unified AI Operations Cockpit: React and TypeScript cockpit unifies spend, quality, incidents, approvals, policy coverage, and prioritized remediation.
- Agent Runaway Firewall: Explainable pre-step ceilings for cost, tokens, tool calls, delegation depth, elapsed time, retries, and emergency stop.
- Run Reservation Ledger: SQLite-backed run reservation and measured-usage reconciliation with duplicate and missing-run protection.
- Schema-Generated Guided Forms: JSON Schema is converted into accessible control metadata with required, range, enum, array, boolean, and sensitive-field guidance.
- Guided Firewall User Flow: Responsive landing-to-evaluation-to-result workflow with loading, success, blocked, and friendly error states.
- Priority Feature APIs: Cockpit summary, runaway evaluation, and form-generation endpoints are available from the Unified Console API.
