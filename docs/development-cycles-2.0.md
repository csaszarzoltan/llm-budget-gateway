# Development cycles

1. Project discovery and baseline: inspected the 1.3 codebase, FastAPI adapters, domain services, tests, docs, build, and existing UI patterns.
2. Catalog and FinOps: implemented capabilities 1-5 and targeted tests.
3. Reliability and compliance: implemented capabilities 6-12 and negative tests.
4. Quality and releases: implemented capabilities 13-20 and contract tests.
5. Product surface: added authenticated API, responsive light/dark dashboard, loading/empty/error/toast states, and accessibility checks.
6. Release hardening: full regression, coverage, Ruff, package build, documentation, Git history, archive cleanup, and Definition of Done review.
